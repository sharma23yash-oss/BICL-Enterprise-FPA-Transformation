# BICL Enterprise Connected Planning and Integrated FP&A Transformation

> **Fictional, synthetic, AI-assisted.** Bharat Industrial Components Ltd. (BICL) is a fictional company and every figure is synthetic. This is an independent educational portfolio project by Yash Sharma, built with Claude's assistance. It is **not** a client engagement, **not** a Deloitte engagement, and **not affiliated with Deloitte or Anaplan**.

An Excel, Anaplan-inspired simulation of a driver-based FP&A model for a fictional five-business-unit industrial group, with the design documents around it: architecture, data audit, scenarios, dashboards, ROI and TCO, operating model, governance, roadmap and change plan.

## What this is, and is not

| It is | It is not |
|---|---|
| A fictional case study with synthetic data | A real engagement or real company data |
| An Excel model (v2.1) tested in LibreOffice 24.2 | Tested in Microsoft Excel (not tested; no Excel compatibility is claimed) |
| A conceptual mapping of the model to Anaplan-style design | A live or built Anaplan model; no Anaplan deployment or certification |
| AI-assisted work; the tests were designed and run by the same assistant | Independently validated |
| Proposals and hypotheses for ROI, governance and change | Measured or realised savings; no benefit has been measured |

## Status of model testing

Model v2.1 has 32 sheets, 12 charts and 106 live QA checks, which all pass in LibreOffice. Of 12 defects: 7 fixed and retested; D-04b, D-08 and D-10 are not testable here; D-12 is descoped; D-09 and D-11 are implemented and LibreOffice-tested with Microsoft Excel verification pending. Details: [VALIDATION_STATUS](documentation/VALIDATION_STATUS.md).

## Known unresolved item

The Phase 1 report shows FY27 revenue 541.45, EBITDA 111.61 and PAT 60.63, which do not agree with v2.1 (576.24, (24.13), (49.63)). The difference is **unexplained pending source-level reconciliation**. See [the reconciliation note](data-audit/BICL_Phase1_FY27_Reconciliation_Note.docx). Only v2.1 figures are used elsewhere.
